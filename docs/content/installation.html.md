# Installation

There are several ways to install Flynn.

To install or configure the Flynn command-line interface, see the [CLI
docs](cli.md).

To install a Flynn cluster on Ubuntu 24.04, follow the [manual installation
guide](installation/manual.md).

To build Flynn or run a local cluster in VirtualBox, use the [Vagrant
environment](installation/vagrant.md).
